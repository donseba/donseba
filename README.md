### 🧰 The Go + Hypermedia Toolkit

A family of focused libraries that snap together into a complete, no-JS-framework web stack for Go.

| Library | What it does |  |
| :-- | :-- | --: |
| **[go-htmx](https://github.com/donseba/go-htmx)** | Seamless HTMX integration — request detection, triggers, swaps &amp; SSE | [![stars](https://img.shields.io/github/stars/donseba/go-htmx?style=flat-square&label=%E2%AD%90&color=00ADD8)](https://github.com/donseba/go-htmx/stargazers) |
| **[go-partial](https://github.com/donseba/go-partial)** | Render full *or* partial pages from HTMX / Turbo / Unpoly headers | [![stars](https://img.shields.io/github/stars/donseba/go-partial?style=flat-square&label=%E2%AD%90&color=00ADD8)](https://github.com/donseba/go-partial/stargazers) |
| **[go-form](https://github.com/donseba/go-form)** | Build, bind &amp; validate HTML forms straight from Go structs | [![stars](https://img.shields.io/github/stars/donseba/go-form?style=flat-square&label=%E2%AD%90&color=00ADD8)](https://github.com/donseba/go-form/stargazers) |
| **[go-router](https://github.com/donseba/go-router)** | Named routes, groups, host routing &amp; middleware on `net/http` | [![stars](https://img.shields.io/github/stars/donseba/go-router?style=flat-square&label=%E2%AD%90&color=00ADD8)](https://github.com/donseba/go-router/stargazers) |
| **[go-importmap](https://github.com/donseba/go-importmap)** | Import maps &amp; CDN asset tags for templates, with vendoring | [![stars](https://img.shields.io/github/stars/donseba/go-importmap?style=flat-square&label=%E2%AD%90&color=00ADD8)](https://github.com/donseba/go-importmap/stargazers) |
| **[go-translator](https://github.com/donseba/go-translator)** | Gettext PO i18n — plural forms, contexts &amp; template helpers | [![stars](https://img.shields.io/github/stars/donseba/go-translator?style=flat-square&label=%E2%AD%90&color=00ADD8)](https://github.com/donseba/go-translator/stargazers) |
| **[go-clue](https://github.com/donseba/go-clue)** | Language server + GoLand/VS Code plugins for Go templates | [![stars](https://img.shields.io/github/stars/donseba/go-clue?style=flat-square&label=%E2%AD%90&color=00ADD8)](https://github.com/donseba/go-clue/stargazers) |
| **[go-webthings](https://github.com/donseba/go-webthings)** | Batteries-included site backend — admin, accounts, CMS &amp; media | [![stars](https://img.shields.io/github/stars/donseba/go-webthings?style=flat-square&label=%E2%AD%90&color=00ADD8)](https://github.com/donseba/go-webthings/stargazers) |
